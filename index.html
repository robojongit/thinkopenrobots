Robotics software, open to everyone

We believe that software for robotics should be open for everyone to use. Optimizing models and harnesses shouldn't happen only inside the labs, and we think that with today's coding agents anyone who wants to can contribute. That's why we started this challenge.

First challenge

Optimizing the harness around Inkling 2 Mini by Thinking Machines to write policy as code.

Everyone uses the same model. Your harness prompts it to write Python that drives simulated robot arms, and the robot only runs code the model wrote. You change the code around the model: the prompts, the control loop, how the scene is shown to it, how it checks and retries its own work.

  • Tasks. Seven RoboSuite tasks in simulation, from the CaP-X benchmark (paper, project page): cube lifting, stacking and restacking, nut assembly, wiping a spill, a two-arm lift and a two-arm handover.
  • Training set. 30 public scenes per task. Run them on your own machine, or on our shared model, as often as you like.
  • Public test. Every submission gets a score on 140 hidden scenes of the same tasks.
  • Private test. 350 hidden scenes decide the final ranking. Half of them are goal variants nobody has seen: new instructions on the same scenes and robot API, so a harness that makes the model reason does better than one that memorises the seven tasks.
  • Starting point. The base solution, the model with the original CaP-X harness, solves about 45% of the public test.
